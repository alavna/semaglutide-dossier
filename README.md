# Semaglutide Evidence Dossier

Read-only research snapshot generated by the Influencer SpecCraft pilot.

Live site: <https://alavna.github.io/semaglutide-dossier/>

## Commands

- `npm run dev` — local development
- `npm run pages:build` — build the static GitHub Pages artifact in `docs/`
- `npm test` — build and verify the rendered dossier and portable Pages output
- `npm run lint` — run ESLint
- `npm run typecheck` — type-check the dossier application

The dossier is for research and editorial planning. It is not medical advice.
